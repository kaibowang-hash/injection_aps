# Injection APS V2 开发计划入口

原单体开发计划已拆分为分阶段、可审计的执行文档，避免长任务实施过程发生需求漂移或跨阶段冲突。

唯一执行入口：

- [APS V2 文档索引与执行路线](./aps_v2/README.md)

执行 AI 不应把本文件当作需求正文，也不应从任意 Phase 文件单独开始。必须按照索引中的阅读顺序、前置条件和阶段门禁执行。

核心规则：

1. [全局不可变契约](./aps_v2/00_GLOBAL_CONTRACT.md) 是最高优先级的业务与技术事实来源。
2. 共享规格只在对应规格文件维护，Phase 文件只引用，不复制另一套公式或状态定义。
3. 每次只允许一个 Phase 处于 `IN_PROGRESS`。
4. 每个 Phase 必须完成代码、迁移、权限、测试、文档和交接证据后才能进入下一阶段。
5. 任何偏离已确认规则的设计，必须先记录 ADR 并获得用户确认，不能由执行 AI 自行改变目标。

# Phase 4 隔离环境工作证据（2026-08-14）

## 1. 结论

Phase 4 于 2026-08-14 完成。有限产能运算已具备不可变整数输入、两层 CP-SAT、独立 Validator、三方案比较、Fallback 明示、指纹防过期和受控 Apply。所有数据库操作仅发生在隔离站点 `aps-opt-fixture.localhost`；`jce.1` 零访问、零写入。

## 2. 关键计算与安全契约

- 数量按输入 `quantity_scale` 整数化，序列时间按分钟整数化；输入、方案和 Apply 均有稳定指纹。
- 第一层全局分配按 P0 准时、加权延期、关键未排、稳定性、准备、连续性、吨位、等价机利用率、P1/P2 的词典序目标求解。
- 第二层精确执行 Machine/Mold `NoOverlap`、Frozen interval、setup/changeover 和确定性排序。
- `minimum_changeover` 只锁定前三层交付最优值，再以准备/换型目标择优；不会把推荐方案的全部效率层锁死成同一方案。
- Validator 独立重算数量守恒、P0 指标、资源重叠、Frozen、Campaign owner 和 BOM precedence；不复用 Solver 约束做自证。
- 原料未进入 Solver hard constraint、输入指纹或 Apply 锁；原料仍是 Phase 3 advisory-only。
- 无可行 CP-SAT 时只生成明确标记的 `Legacy Fallback`，必须确认风险；空正式排程不可 Apply。
- Apply 在公司、Run、Commitment、Result、Segment 的固定锁顺序内重验输入与方案指纹。
- Trial 在 V2 投影前保存 Legacy baseline/fingerprint 到 Solver Job audit；Scenario 页面展示 Legacy、V2 和 delta。Trial 始终只读，前端按钮显示禁用原因，后端仅允许 `run_type=Formal` Apply。
